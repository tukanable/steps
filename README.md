# steps — original sin

Визуализация к идее «original sin»: 1000 путников идут к цели фиксированным шагом.
Шаг фиксированный — под дистанцию не подогнать, поэтому путник вечно **перескакивает**
цель и не может на ней остановиться. Чем больше шаг, тем больше перескок и разброс;
при огромном шаге — улетает в бесконечность.

Анимация синхронизирована с озвучкой (ElevenLabs `eleven_v3`, символьные таймстемпы):
кнопка **Play** запускает голос и движение. По ключевым словам меняются число точек
(1 → «сто» → «тысячу»), размер шага и скорость анимации (проседает до минимума на
слове «минимальной», чтобы рассмотреть пульсацию). Снизу идут субтитры, на финале —
CTA и остановка (стоп-кадр). Cue-точки заданы в `script.js` (STEP_KF, SPEED_KF, COUNT_CUES).

## Файлы
- `index.html`, `style.css`, `script.js` — страница и логика (canvas, чистый front-end).
- `timeline.js` — запечённые тайминги слов/предложений (работает и по `file://`).
- `narration.mp3` + `narration.align.json` — озвучка и сырые таймстемпы.
- `gen_voice.py` — генерация озвучки и пересборка `timeline.js`
  (ключ ElevenLabs читается из `../instagen/.env`, в репозиторий не попадает).

## Музыка после реплик (опционально)
Положи свой аудио-клип файлом `outro.mp3` в папку проекта — он заиграет **один раз
после озвучки**, первые 33 секунды, с fade in/out (параметры `OUTRO_*` в `script.js`).
Файл в репозиторий не коммитится (`.gitignore`) — не выкладывай чужой копирайт в паблик.

## Запуск
```
python3 -m http.server 8731
# открыть http://localhost:8731/index.html → Play
```
Или просто открыть `index.html` в браузере.

## Перегенерация озвучки
```
python3 gen_voice.py   # переписывает narration.mp3, narration.align.json, timeline.js
```
Кривая размера шага — массив `KF` в `script.js`. Ползунок «ручной шаг» (0–30) —
песочница вне режима Play.
